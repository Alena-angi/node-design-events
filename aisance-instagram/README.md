# Aisance — Instagram refresh (concept)

Логотип у макетах — **тимчасовий плейсхолдер** (лаймове коло з дугою). Замінити на новий лого, коли буде папка з оновленнями.

- `posts.html` — 3 пости 1080×1350 (4:5)
- `grid.html` — як вони виглядають у профілі (сітка 3:4)
- `out/` — готові PNG
- Перегенерувати: `node aisance-instagram/render.js`

**Палітра:** forest `#0C2620` · lime `#C9F26B` · cream `#F1ECE3` · ink `#0B1F1A`
**Шрифти:** Geist (заголовки / текст) + Instrument Serif Italic (акцентне слово) + Geist Mono (службові підписи)

Ритм сітки: темний → світлий → лайм. Публікувати в порядку 1 → 2 → 3, пост 1 закріпити.
